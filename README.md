## Compilation en ligne
Le workflow GitHub Actions \`.github/workflows/build-msi.yml\` compile l'application et produit un artefact \`GarageGestion-Setup.msi\`.
1. Ouvrir l'onglet **Actions** du dépôt.
2. Sélectionner **Build Garage Gestion MSI**.
3. Cliquer sur **Run workflow** ou pousser un commit.
4. Télécharger l'artefact **GarageGestion-Setup** lorsque le build réussit.

## Prérequis cible
Windows 7 SP1 ou version ultérieure avec .NET Framework 4.8 installé.

## État du prototype
Cette première livraison est un squelette d'interface. Les modules métier, la base SQLite, la génération PDF, la comptabilité et les tests sur Windows 7 restent à développer. Ne pas utiliser cette version pour la comptabilité réelle.
